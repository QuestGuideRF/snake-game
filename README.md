# 🐍 Змейка (Console Snake Game)

Классическая игра "Змейка" в консоли с красивой графикой и плавным управлением.

## 📝 Описание

Управляйте змейкой, собирайте яблоки и избегайте столкновений! Чем больше яблок съедите, тем длиннее станет ваша змейка и тем быстрее будет игра.

## ✨ Возможности

- 🎮 **Плавное управление** с помощью WASD
- 🍎 **Случайное появление еды** на игровом поле
- 📈 **Система подсчёта очков** (10 очков за каждое яблоко)
- 🚀 **Увеличение скорости** по мере роста змейки
- 💥 **Проверка столкновений** со стенами и собой
- 🎨 **Красивая графика** с Unicode символами
- 🏆 **Система рейтингов** (Новичок → Любитель → Эксперт → Мастер)

## 🎯 Правила игры

1. **Цель**: Собрать максимальное количество яблок 🍎
2. **Движение**: Змейка постоянно движется в выбранном направлении
3. **Рост**: Съедая яблоко, змейка увеличивается на один сегмент
4. **Ускорение**: С каждым съеденным яблоком игра становится быстрее
5. **Проигрыш**: Игра заканчивается при столкновении со стеной или собой

## 🚀 Запуск игры

```bash
python snake_game.py
```

### 📋 Требования
- Python 3.6 или выше
- Терминал с поддержкой Unicode

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `W` | Движение вверх ⬆️ |
| `S` | Движение вниз ⬇️ |
| `A` | Движение влево ⬅️ |
| `D` | Движение вправо ➡️ |
| `Q` | Выход из игры 🚪 |

## 🎨 Игровые элементы

- **► ◄ ▲ ▼** - Голова змейки (показывает направление)
- **●** - Тело змейки
- **🍎** - Яблоко (еда)
- **█** - Стены игрового поля

## 📊 Система очков

- **🍎 Яблоко**: +10 очков
- **🏆 Рейтинги**:
  - 0-49 очков: Новичок 🥉
  - 50-149 очков: Любитель 🥈
  - 150-299 очков: Эксперт 🥇
  - 300+ очков: Мастер 👑

## 🎯 Советы для игры

1. **Планируйте маршрут** - думайте на несколько ходов вперёд
2. **Используйте стены** - двигайтесь вдоль границ для безопасности
3. **Не торопитесь** - лучше медленно, но верно
4. **Избегайте углов** - легко попасть в ловушку
5. **Тренируйтесь** - с каждой игрой вы будете играть лучше!
